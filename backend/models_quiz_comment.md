
# 🧠 Quiz & Discussion Mongoose Models

---

## 📄 Quiz Model

```js
{
  lesson: ObjectId,           // Linked lesson
  title: String,              // Quiz title
  description: String,        // Optional description
  isAIgenerated: Boolean,     // True if generated by AI
  createdBy: ObjectId,        // User who created the quiz
  timestamps: true
}
```

---

## 📄 Question Model

```js
{
  quiz: ObjectId,             // Linked quiz
  questionText: String,       // The question
  options: [String],          // Multiple choice options
  correctAnswer: String,      // The correct option
  explanation: String,        // Optional explanation
  difficulty: "easy" | "medium" | "hard",
  isAIgenerated: Boolean,     // Flag for AI creation
  timestamps: true
}
```

---

## 📄 Comment Model

```js
{
  lesson: ObjectId,           // Linked lesson
  author: ObjectId,           // Commenting user
  content: String,            // Comment text
  parent: ObjectId,           // For replies
  roleAtPostTime: "student" | "instructor" | "admin" | "superadmin",
  isEdited: Boolean,          // Track edits
  isDeleted: Boolean,         // Soft delete
  reported: Boolean,          // Moderation flag
  timestamps: true
}
```

---

These models are **AI-ready**, support moderation, and allow clean threading for comments and quizzes.
